# Отчёт · учебный кабинет (навигация)

## Удалённые лишние действия
- Постоянные ссылки шапки «Главная», «Программа», «Прогресс»
- Маркетинговый hero / рассказ о проблеме проекта на главной
- CTA «Начать урок / Продолжить обучение / Попробовать…»
- Дубли прогресса на главной рядом с нав
- Ярлык «К программе» → «К курсу» (обзор курса)

## Что вместо
- Шапка: бренд слева, профиль **Иса Дадашев** справа
- Панель профиля: прогресс, баллы (100 × unique accepted), тема, подробный прогресс, сброс внизу
- Главная: «Моё обучение» + кликабельная карточка «Основы Python» (`N/2 задач зачтено`, progress bar), без кнопок Начать/Продолжить (как у LMS-референса)
- `/program` — обзор курса: Урок → Задача 1 → Задача 2 + план

## Проверки
- typecheck, learning tests, E2E — OK
- Баллы из `acceptedExerciseIds`, не отдельный счётчик
- Preview + production — после деплоя
