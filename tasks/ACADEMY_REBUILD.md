# Пересборка учебного кабинета

Tag freeze: `cabinet-base-2026-11-08` (= main до переделки). Работа в `feat/academy-rebuild`. Production не трогаем до проверки preview.

## Схема экранов

```
/  Моё обучение
   ├─ карточка «Python для AI» → /courses/python
   └─ карточка «Основы AI» · Готовится (без прогресса)

/courses/python  Курс
   цель + прогресс только по доступным задачам (сейчас 0–2)
   4 блока: Первые программы → Условия… → Циклы… → Функции…
            [доступен]         [готовится]  [готовится]  [готовится]

/courses/python/first-programs  Блок
   слева: уроки + задачи со статусами
   справа: открытый урок / переход к задаче
   mobile: «Содержание блока»

/learn/python/variables  Урок (сохраняем URL)
/practice/variables|session-minutes  Задача (сохраняем URL)
   условие | редактор | вердикт; попытки без чужого кода

/progress  Подробный прогресс + «Что повторить»
/skills    Карта навыков (только evidence)
/rating    Демо рейтинга (вымысел, постоянная пометка)
```

## Удаляем из нынешнего UI

- Жёсткое имя «Иса Дадашев» в шапке
- Шесть больших недоступных модулей на главной
- Вид «нулевого освоения» у будущих блоков/курсов
- Конкурирующие CTA / рекламный шум на учебном пути
- Статус «Ждёт проверки», дедлайны, преподавательские оценки
- Утверждения об аккаунте и синхронизации
- Смешение демо-рейтинга с личными баллами

## Сохраняем

- `learning:v1` (черновики, Attempt, Mastery, lastLocation)
- Pyodide, grade, mentor prepared hints
- Рабочие маршруты `/learn/...`, `/practice/...`
