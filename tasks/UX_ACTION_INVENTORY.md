# Инвентарь видимых действий (до упрощения)

Принцип ориентира (Яндекс Образование / Практикум): теория → одно «Перейти к заданию» → в тренажёре главное «Проверить», подсказка по запросу. Фирменный стиль не копируется.

| Экран | Действие | Роль | Решение |
|---|---|---|---|
| Нав | Главная / Программа / Прогресс | глобальная навигация | оставить |
| Нав | Тема / О платформе | второстепенное | оставить в меню |
| Главная | Попробовать / Продолжить | **главное** | оставить одно CTA: «Начать урок» / «Продолжить обучение» |
| Главная | Открыть урок / Сразу к задаче / Прогресс | дубль нав + CTA | **удалить** |
| Главная | Цикл с готовым решением | раскрывает ответ | **удалить** |
| Главная | Сводка прогресса + about | вторично | кратко «что доступно»; about — тихая ссылка |
| Урок | TOC разделов | ориентация | оставить |
| Урок | Помощь с темой (ранняя + TOC) | конкурирует с чтением | помощь после теории / details, не яркий CTA |
| Урок | Самопроверка | контекст | оставить в потоке |
| Урок | Перейти к практике | **главное в конце** | оставить одно |
| Практика | Проверить | **главное** | визуально главное, у редактора |
| Практика | Запустить | вторичное | secondary |
| Практика | Оценить текущий код (×2) | дубль «Проверить» | **удалить** |
| Практика | Подсказка / Помощь по ошибке | по необходимости | одна раскрываемая «Подсказка» |
| Практика | Скачать / шаблон / редактор | редкое | только в «Ещё» |
| Практика | Ссылка на раздел урока в каждом issue | шум | одна ссылка в подсказке / после ошибки |
| Программа | Открыть доступный урок | главное | оставить; planned явно «готовится» |
| Прогресс | Продолжить | **главное** | одно CTA |
| Прогресс | Сбросить данные | опасное / редкое | тихая ссылка, не рядом по весу |
