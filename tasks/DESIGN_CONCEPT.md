# Дизайн-концепция · CHGU AI Academy (конкурсный редизайн)

## Характер
**«Учебный стол»** — спокойная образовательная платформа для новичка в Python: ясная иерархия чтения, живой пример кода как главный визуальный якорь, без маркетингового шума и без SaaS-карточек.

## Палитра (светлая / тёмная)
- Paper: `#F3F5F4` / ink surface `#141A1C`
- Ink: `#1B2430` / `#E6EAE8`
- Accent (действие): teal `#0F6B62` — только интерактив
- Caution (ошибка): `#9B4030`
- Success: `#2F6A4E`
- Line / muted: спокойные серо-зелёные нейтрали

## Типографика
- Заголовки / бренд: Source Serif 4
- UI и длинный текст: Source Sans 3
- Код: IBM Plex Mono

## Сетка и принципы
- 8pt ритм; контент урока ≤ ~68ch
- Один primary CTA на экран героя: «Попробовать урок»
- Главный акцент — компактный цикл «код → ошибка → подсказка → исправление», не абзац
- Ограничения (1 урок / 2 задачи) вторичны и доступны, не в hero-фокусе
- Без стоковых фото, гербов, случайных градиентов и декоративных «карточек ради карточек»
