# Схема: семь модулей → два курса

## Главная `/`
Моё обучение
- Программирование и данные → /courses/programming
- AI Engineering → /courses/ai-engineering

## Курс `/courses/[courseId]`
Название курса
Список модулей (из curriculum.ts), без рекламных описаний.
Прогресс строки только если у модуля есть опубликованные задания.

## Модуль `/modules/[moduleId]`
Слева шире: Практические занятия (группы → строки задач + статус)
Справа: Материалы (опубликованные уроки: разделы + видео-заглушка + прогресс)
Ниже/сбоку план неопубликованных тем — только названия.

## Задача `/practice/[key]`
Назад → условие → Пример работы программы → редактор/вердикт
