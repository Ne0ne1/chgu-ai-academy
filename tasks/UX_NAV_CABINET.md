# Навигация учебного кабинета (до → после)

Референс организации: спокойный список курсов + профиль справа (Яндекс LMS). Без копирования логотипа/фирменного стиля. Приватные скриншоты аккаунта не коммитятся.

| Было | Роль | Решение |
|---|---|---|
| Шапка: Главная / Программа / Прогресс | постоянный шум | **убрать** |
| Шапка: Гость | профиль | **Иса Дадашев** + панель |
| Главная: hero «проблема/прототип», CTA «Начать урок» | маркетинг | **Моё обучение** + карточка курса |
| Дубли прогресса на главной и в нав | дубль | прогресс/баллы в **профиле** |
| «К программе» с практики | лишний ярлык | обзор курса `/program` из карточки/хлебных крошек |
| Баллы | не было | 100 × unique accepted (`acceptedExerciseIds`) |

Маршруты сохранены: `/`, `/program`, `/progress`, `/learn/...`, `/practice/...`.
