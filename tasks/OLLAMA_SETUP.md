# Локальная модель для учебного наставника

Наставник обращается к Ollama **только с сервера Next.js** (`OLLAMA_BASE_URL`). Браузер не передаёт URL модели. Адрес `127.0.0.1` — это машина, где запущен сервер приложения, а не компьютер каждого студента публичного сайта.

## Установка (вручную)

1. Установите [Ollama](https://ollama.com) на машину, где крутится `next dev` / `next start`.
2. Скачайте модель сами, например:
   ```bash
   ollama pull llama3.2:3b
   ```
3. Проверьте список:
   ```bash
   curl http://127.0.0.1:11434/api/tags
   ```

Проект **не** скачивает крупные модели автоматически.

## Настройки сервера

Создайте `.env.local` (не коммитьте секреты; для Ollama обычно достаточно локального URL):

```bash
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2:3b
OLLAMA_TIMEOUT_MS=20000
```

Перезапустите Next.js после изменения переменных.

## Проверка

```bash
curl -s http://127.0.0.1:3000/api/mentor
# {"available":true,"model":"llama3.2:3b",...}
```

В уроке: «Нужна помощь?» → «Получить объяснение».  
В практике после ошибки: «Подсказка» → при необходимости отметьте передачу кода → «Помощь по ошибке».

Если модель недоступна, интерфейс честно показывает **подготовленные подсказки** и не ломает урок/практику.
